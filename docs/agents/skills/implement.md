# Implement in keelrs

Repo rules for `/implement`. They add to the upstream skill; where the two disagree, this file wins.

Before the first edit, read the ticket against `AGENTS.md` "Code" and list every design decision the ticket does not settle: state, concurrency, types and names, contracts, parallel paths. Ask about them in one message, with options and a recommendation, and wait for the answer. Build only what the ticket and the answers settle. A question that comes up later is asked before its code is written, never reported after it.
